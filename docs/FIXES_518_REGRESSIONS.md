# Исправления репортов для 23 Race Forever 1.6.518

Рабочая база расследования: `origin/main`, `c6da627`. Обновление выполнено fast-forward с сохранением существовавших незатреканных файлов. Исправления включены в релиз 1.6.519; ниже сохранены результаты проверки диагностической сборки 518.

## Проходимость и область всего мира

Между тегом 517 и текущей 518 в `NagaCombat.Init`, `OgreCombat.Init` и `PandarenBrew.Init` появились три отдельных `CreateRegion` / `RegionAddRect(GetWorldBounds())`. Эти регионы создавались во время инициализации триггеров. В проекте уже задокументирована чувствительность проходимости к позднему созданию мирового региона: [предыдущее расследование](FEC12DE_MOVEMENT_INVESTIGATION.md).

Три обработчика теперь подписываются на существующий `Allmap`, созданный в корневом Lua. Новые мировые регионы и временные прямоугольники этим механикам больше не нужны. Мутация наг, учёт гроннов и автоприменение пандаренов сохранены. Инициализаторы сохраняют защиту от повторной регистрации.

`war3map.wpm`, `war3map.w3e`, `war3map.doo` и `war3mapUnits.doo` между 517 и подтянутым `main` не менялись. Существующий индексатор юнитов сохранён.

Это исправление повторно появившегося опасного паттерна. Связь именно этих трёх регионов с движением в 518 и зависанием при перезапуске ещё требует проверки в Warcraft III.

## Случайный найм и исследования Орды

- Девять обработчиков случайного найма пересчитывают соответствующий состав перед выбором замены. Отсутствующий или устаревший кеш больше не даёт выбор из диапазона `1..0` и замену на rawcode `0`. Регрессия воспроизводила ошибку на пустом кеше до исправления. Все 71 ID юнитов, встречающиеся в обработчиках найма, найдены через HiveWE.
- Доступность взаимоисключающих исследований пересчитывается по завершённым и начатым исследованиям отдельно для каждого игрока. Отказ от расширения блокирует расширение; «Общий дом», «Истинная Орда» и «Компромисс» исключают друг друга; Железная Орда и Орда Ша тоже исключают друг друга. Отмена восстанавливает только доступные по предпосылкам варианты. Начало исследования предпосылки само по себе не открывает следующую ветку.
- Обработчик доступности регистрируется после прежних обработчиков эффектов и учитывает их итоговые изменения технологий. После завершения исследования также обновляются составы войск.
- Исправлены неверные ID: отмена «Общего дома» — `R0EH`, ночнорождённые — `R0F4`, магнатавры — `R0E5`.

## Ложная «Ярость вурдалака»

У 57 кастомных пассивных способностей с кодом `APai` обнаружено унаследованное требование `Rugf`, включая «Сбор дани» и «Налаженное производство». Для них добавлено пустое поле `areq` в основной и HD таблицах: 57 изменений в каждой. Сама способность `Augf` сохраняет `Rugf`.

Повторяемая правка: [fix_passive_requirements.py](../scripts/fix_passive_requirements.py). Используется существующий писатель строковых полей, сохраняющий заголовки v3 и байты остальных модификаций. Результат независимо прочитан через HiveWE. Резервные файлы и журнал результата находятся в `.cache/wc3/passive-requirements-*`.

Предварительная попытка штатной транзакции HiveWE выявила повреждение v3 при записи во временную копию. Исходная карта этой попыткой не менялась. Поэтому финальная правка сделана через побайтово сохраняющий писатель проекта.

## Чат-команды

Подтянутые исправления регистрации `-gg`, `-observer` и `-observeroff` проверены для всех 24 игровых слотов; проверена повторная команда наблюдателя и отключение обзора.

Дополнительно исправлены `-cam`, `-arhont` и `-arhoff`: используется общий разбор полного аргумента, камера не обрезает расстояние до четырёх цифр и отклоняет нечисловые/недопустимые значения; передача управления принимает только целые номера игроков 1–24. Номер 25 и частично числовые строки отклоняются.

- `wc3_tools.py build`: Lua пересобран из split-секций.
- `wc3_tools.py check --kind lua`: source-sync, синтаксис Lua, AI schema и все **213 тестов** прошли. У AI остаются 72 предупреждения миграции при нуле ошибок схемы.
- В [test_518_regressions.py](../tests/test_518_regressions.py) добавлено 10 регрессий с дополнительными проверками для всех категорий найма и игровых слотов.
- Полный аудит с `docs/audit-baseline.json` не зелёный: три находки по таймерам в неизменённых `CustomHud_Create`, `HostPanel_Open`, `RacePicker_Create`; двум аудиторам не хватает исходного `war3map.j`. Baseline не менялся. Отдельный запуск этих двух аудиторов по доступным `common.j`/`Blizzard.j` дал по 0 находок; это не восполняет отсутствующие сигнатуры старого скрипта карты.
- Справочник зависимостей перегенерирован для 36 рас; штатный генератор в режиме `--check` вывел `OK`. При повторной сверке ответы CLI переиспользовались только после проверки неизменности хешей данных карты. После разового падения локального CLI экспорт выполнен повторно; исходные данные не изменялись. Результат: `.cache/wc3/techtree-final.log`. В сгенерированном diff также меняется порядок свойств, возвращаемых локальной версией CLI: 37 изменённых файлов, из них 21 с изменением содержания JSON.
- Тестовый архив успешно собран: [23_Race_Forever_v1_6_518_fixes.w3x](../23_Race_Forever_v1_6_518_fixes.w3x), 125835616 байт, SHA256 `0976b10c042dc816ace20c6cfc1e85ae73996ead04e325163389100cabb06ea9`.
- Автоматическая игровая проверка [movement-518.json](../tests/scenarios/movement-518.json) завершилась тайм-аутом свежего heartbeat до выполнения шагов. Запуск нужной карты не подтверждён; измерений движения нет. Отчёт: `.cache/wc3/scenarios/f42e0bc2ca934de1a0f24b004fff5579/report.json`. Диагностический процесс закрыт.

Для игровой приёмки остаются: движение воргенов и обычных наземных юнитов, повторный запуск карты, реальный найм разных категорий Орды, отмена и завершение взаимоисключающих веток, отображение подсказок SD/HD.
