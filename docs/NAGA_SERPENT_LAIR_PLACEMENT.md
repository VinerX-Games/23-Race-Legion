# Логово змеев: размещение

`n04L` — Serpent's Lair, нанимает только `n079` (Sea Serpent).
Остальные здания наг допускают строительство на суше; это здание является
исключением и предназначено для мелководья.

- `preventplace=unwalkable,unfloat`: запрещены клетки без возможности ходьбы
  (глубокая вода) и без возможности плавания (суша).
- `movetp=float`: восстановлен прежний тип перемещения здания.
- `requireplace` остаётся пустым, `pathtex=PathTextures\4x4SimpleSolid.tga`.

До массовой правки `5a5494c` у здания было `preventplace=unfloat` и
`movetp=float`. Теперь ограничение дополнительно исключает глубокую воду,
согласно требованию строительства именно на мелководье.

План транзакции: [naga-serpent-lair-placement.json](naga-serpent-lair-placement.json).
`scripts/fix_naga_buildings.py` исключает `n04L` из списка разрешения суши.

В движке нужно проверить три попытки строительства: суша и глубокая вода
запрещены, свободное мелководье допускается. Проверка object data не заменяет
этот игровой тест.
