# Результат внедрения инструментов

Дата: 2026-10-13. Рабочие команды и конфигурация: [TOOLING_WORKFLOW.md](TOOLING_WORKFLOW.md).

## Реализовано

- Исправлены exit codes проверки сборки и обязательных проверок; AI-валидатор читает manifest и разделяет ошибки/предупреждения.
- Общий загрузчик manifest проверяет отсутствующие, повторные и выходящие за каталог записи. Маппинг учитывает общие строки секций, сохраняет source map с хешами и не показывает изменённый исходник как контекст старой сборки.
- Добавлены `doctor`, `symbol`, `refs`, `context`, `check`, JSON, ограничения вывода и индекс по содержимому. Аудиторы используют один AST и явный baseline известных находок.
- Исправлен контракт поиска HiveWE; подключены bulk, дерево технологий, полный semantic diff, staged transactions и восстановление. Копируются также Skin-таблицы; проверяются повторное чтение и отсутствие посторонних изменений effective fields.
- Добавлены игровые сценарии, nonce-проверка связи, блокировка общего bridge-канала, сбор отчётов и упаковка отдельного MPQ перед запуском.
- Исследованы `src/cli`, `src/model_editor`, сериализация object data и проходимость форка [VinerX/HiveWE](https://github.com/VinerX/HiveWE). Воспроизводимый патч — [patches/README.md](../patches/README.md).
- Собран headless CLI без Qt: JSON schema v1, capabilities, `validate-map`, ассеты/CASC, fresh heartbeat, проверка фокуса, отказ при неизвестном поле, корректная запись main/Skin и подсчёт сериализованных полей. Для текстовых изменений создаётся отдельная WTS-запись.
- Подключён существующий MDLxL CLI для диагностики, текстур и превью; GUI MDLxL не изменялся.
- Добавлен слой начальной проходимости размещённых препятствий: 36 871 размещение прочитано, 21 036 footprints применено, 16 999 ячеек изменено. Файлы исходной карты не меняются.
- Созданы `wc3-change-check`, `wc3-live-scenarios`, `wc3-model-assets`; обновлены `wc3-tools`, `wc3-hivewe`, `wc3-lua-debug`, `wc3-ai-brain`.

## Проверки и измерения

- 33 Python regression tests прошли; все 9 локальных скиллов прошли валидатор.
- Проверки синхронизации, Lua-синтаксиса и AI-схемы прошли. Текущий AI: 32 определения, 0 ошибок схемы, 72 замечания миграции.
- Native CLI собран MSVC 19.44; capabilities и упаковочный MPQ-контракт прошли. Unicode overlay-порты нужны для CascLib и StormLib.
- На полной копии карты изменены HP и имя рабочего. Повторное чтение и semantic diff подтвердили требуемый результат без посторонних изменений. Откат восстановил все скопированные файлы, включая main/Skin/WTS, до исходных хешей.
- Подтверждён отказ CLI при неизвестном поле. Модель PeasantFemale проверена и отрендерена; выявлены только предупреждения по вырожденным треугольникам.
- На одном запросе model info stdout сократился с 7363 до 630 байт; полный JSON сохранён. Восьмистрочный контекст Lua — 582 байта. Это измерение объёма вывода, а не обещание процента экономии токенов во всех задачах.

## Существующие находки и ограничения

Статический baseline содержит 102 известные находки, преимущественно эвристический баланс handles. Они не объявлены исправленными или безопасными. Object data: 38 ошибок ссылок/WTS и 248 предупреждений по ассетам, сохранённых в [object-data-findings.json](object-data-findings.json). Эти игровые данные в рамках улучшения инструментов не изменялись; исправления требуют оценки намеренного поведения.

Игровая проверка готовности не завершена: Warcraft III остановился на экране входа в Battle.net, карта и heartbeat не появились. Оба попытанных варианта запуска возвращают провал, а не ложный успех. После самостоятельного входа пользователя требуется повторить readiness, затем AI-growth/build-caps. Отчёт failed probe находится в `.cache/wc3/scenarios/9fe3893614c74ec8a8ae676d88f0d874/`.

Снимок проходимости не учитывает изменения во время игры — открытые ворота, уничтоженные деревья и движущиеся юниты. Attach-сценарий подтверждает свежий ответ моста, но не доказывает хеш байтов уже загруженной карты. Нативный CLI остаётся отдельной локальной сборкой, выбранной в `wc3.local.json`; установленный HiveWE сохранён. Внешние плагины не устанавливались: необходимые операции доступны локально.
