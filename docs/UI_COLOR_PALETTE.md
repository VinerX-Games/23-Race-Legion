# Единая палитра текста — обязательный стандарт

Утверждённая пользователем палитра для всей карты: всех рас, названий, описаний, сообщений и интерфейса. Применять при каждом добавлении и изменении игровых текстов. Первые три цвета выбраны пользователем. Остальные — вариант «Тёплое золото», выбранный пользователем 2026-10-17 вместо прежней схемы с низким контрастом и голубым. Структура подсказок описана в [UI_TEXT_STYLE.md](UI_TEXT_STYLE.md). Утверждение стандарта само по себе не означает, что все существующие тексты уже приведены к нему.

| Роль | HEX | Warcraft III | Применение |
|---|---|---|---|
| Основной текст | `CED4DA` | `\|cffced4da` | Описания, сообщения, подписи параметров |
| Выделение | `FFFFFF` | `\|cffffffff` | Урон, длительность, радиус, важные слова, горячие клавиши |
| Положительный эффект | `C8E087` | `\|cffc8e087` | Лечение, бонусы, доступность, успешные действия |
| Отрицательный эффект / ошибка | `EF8173` | `\|cffef8173` | Штрафы, потеря ресурсов, недоступность, ошибки |
| Внимание / условие | `F2A35E` | `\|cfff2a35e` | Ограничения, требования, предупреждения, важные изменения правил |
| Названия / заголовки | `EBC56C` | `\|cffebc56c` | Имена юнитов, героев, зданий, способностей, исследований; заголовки интерфейса |
| Второстепенный текст | `B99D66` | `\|cffb99d66` | Начальная метка типа («ЮНИТ:», «ЗДАНИЕ:» и т. п.), тип способности, справочные примечания, художественное описание |
| Названия в списках | `EBC56C` | `\|cffebc56c` | Связанные юниты, исследования, способности в списках и тексте; ники авторов и периоды. Тот же цвет, что у заголовков (голубой `A9C7DE` отменён 2026-10-17) |
| Шкала сложности | `C8E087` / `F0CB5C` / `EF8173`, пустые `5F6874` | — | Заполненные `●`: 1–2 зелёные, 3–4 жёлтые, 5 красные; пустые `○` тёмно-серые |

## Правила применения

- Все названия используют один цвет: без отдельной палитры для каждой расы и каждого типа юнита. Цвета игроков и команд сохраняют своё значение принадлежности.
- Обычные числовые характеристики белые. Числа бонусов и штрафов окрашиваются по смыслу. Например: «Наносит 120 урона» — белое число; «Повышает урон на 20» — зелёный бонус; «Снижает урон владельца на 20» — коралловый штраф.
- Цвет эффекта отражает результат для владельца: замедление врага в описании атакующего заклинания можно оставить белым, а штраф поражённого юнита в описании отрицательного эффекта — коралловым.
- Янтарный означает «обрати внимание», коралловый — «неблагоприятно / невозможно». Выполненное требование зелёное, невыполненное — коралловое.
- Не окрашивать целиком длинные описания эффектов. Выделять короткие фразы и значения; основной текст оставлять серым.
- Не передавать смысл только цветом: писать «Требуется», «Недоступно», «Бонус», использовать знаки +/− там, где они уместны.
- Справочный голубой необязателен: если ссылка не помогает найти связанную механику, достаточно основного текста или белого выделения.

## Пример подсказки

Название: «Озарённый клинок» — `EBC56C`.

Тип: «Пассивная способность» — `B99D66`.

Описание: «СПОСОБНОСТЬ: Следующая атака наносит 30 дополнительного урона» — начальная метка `B99D66`, основной текст `CED4DA`, число `30` белое.

Условие: «Требуется не менее 85% здоровья» — подпись `F2A35E`, число белое.

Положительный эффект: «Полученное лечение сокращает перезарядку на 2 сек.» — основной текст, фраза «на 2 сек.» зелёная.

## Встраивание в строки Warcraft III

Цвет задаётся как `|cffRRGGBB`, сброс — `|r`. `ff` обозначает полную непрозрачность. После выделения внутри серого описания следует снова установить серый: сброс не восстанавливает предыдущий цвет.

```text
|cffebc56cОзарённый клинок|r
|cffb99d66Пассивная способность|r
|cffb99d66СПОСОБНОСТЬ:|cffced4da Следующая атака наносит |cffffffff30|cffced4da дополнительного урона.|r
|cfff2a35eТребуется не менее |cffffffff85%|cfff2a35e здоровья.|r
|cffced4daПолученное лечение сокращает перезарядку |cffc8e087на 2 сек.|cffced4da.|r
```

Визуальный образец: [ui-color-palette.svg](ui-color-palette.svg). Оттенки следует окончательно оценить в игре с используемым шрифтом и фоном подсказок.
