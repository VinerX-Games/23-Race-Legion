# 23 Race Forever v1.6.519

Исправления репортов по версии 1.6.518.

## Что изменено

- Убраны три дополнительных региона на весь мир, добавленные в 518 для наг, огров и пандаренов. Их обработчики используют существующий ранний `Allmap`, сохраняя механики рас. Это устраняет повтор ранее обнаруженного опасного для проходимости паттерна инициализации.
- Случайный найм Орды пересчитывает состав перед заменой юнита, чтобы пустой или устаревший кеш не приводил к исчезновению нанятого бойца.
- Взаимоисключающие решения Орды блокируются при начале исследования. Отмена восстанавливает доступные варианты с учётом предпосылок. Исправлены ID обработчиков отмены «Общего дома», ночнорождённых и магнатавров.
- У 57 кастомных пассивных способностей убрано ложное унаследованное требование «Ярость вурдалака» в основной и HD таблицах, включая «Сбор дани» и «Налаженное производство». Настоящая способность вурдалака сохраняет своё требование.
- Команда `-cam` читает полное расстояние и отклоняет неверные значения. Команды `-arhont` и `-arhoff` принимают только целые номера игроков 1–24.
- Включён находившийся после тега 518 коммит `c6da627`: исправления регистрации чат-команд, стартовых лимитов Орды, щупалец Йогг-Сарона и выбора личинок силитидов.

## Проверки

- 213 автоматических тестов прошли, включая 10 новых регрессий и загрузку/завершение лобби с моделью Warcraft natives.
- Проверены синтаксис Lua, совпадение split-исходников со сборкой и схема AI: 0 ошибок, 72 существующих предупреждения миграции.
- База зависимостей 36 рас перегенерирована; проверка генератора дала `OK`.
- Изменения object data проверены чтением через HiveWE и сравнением байтов: меняются только поля требований целевых пассивок.

## Что ещё требует проверки в игре

Движение воргенов и других наземных юнитов, зависание при перезапуске, реальный найм и переключение веток Орды, подсказки SD/HD и сетевой матч не подтверждены игровым прогоном. Попытка автоматической проверки движения завершилась до измерений: игровой мост не выдал свежий heartbeat, загрузка нужной карты не была подтверждена.

Полный статический аудит также сохраняет ограничения: три находки по таймерам в неизменённых обработчиках интерфейса и отсутствие старого `war3map.j` для двух аудиторов. Отдельная проверка этих двух аудиторов по доступным сигнатурам `common.j`/`Blizzard.j` дала 0 находок. Baseline аудита не изменялся.
